# 🪓 [Nom de votre jeu] – Projet Timber SFML 3.1

Version enrichie, modulaire et personnalisée du jeu d'arcade classique **Timber**, réalisée en **C++** avec la bibliothèque multimédia **SFML 3.1** dans le cadre du cours **INFO4006 – Multimédia**.

## 🎮 Fonctionnalités principales

* **Menu principal interactif :** Navigation complète au clavier avec écran d'instructions intégré, gestion des états du jeu (*Menu, Jeu, Pause, Fin de partie*) et redémarrage rapide sans relancer l'application.
* **Trois niveaux de difficulté :** Modes *Facile*, *Normal* et *Difficile* ajustant dynamiquement la vitesse des obstacles, le rythme du chronomètre et la génération des branches.
* **Nouvelle mécanique de jeu :** [Ex. : Bouclier protecteur / Système à 3 vies / Objets bonus à collectionner / Bonus de temps — *à adapter selon ton choix*].
* **Système de pointage avancé :** [Ex. : Multiplicateur de combo / Sauvegarde persistante du Top 5 des meilleurs scores dans un fichier texte — *à adapter selon ton choix*].

## 🛠️ Technologies utilisées

* **Langage :** C++ (C++17 ou supérieur)
* **Bibliothèque graphique & audio :** SFML 3.1 (`sfml-graphics`, `sfml-window`, `sfml-system`, `sfml-audio`)
* **IDE :** [Visual Studio 2022 / CLion / Code::Blocks — *à adapter*]

## 🚀 Installation et exécution

1. Cloner ce dépôt :
   ```bash
   git clone https://github.com[votre-utilisateur]/[nom-du-depot].git
   ```
2. S'assurer que la bibliothèque **SFML 3.1** est correctement configurée dans votre environnement de développement.
3. Ouvrir le fichier de solution/projet et compiler en mode **Release** ou **Debug**.
4. Vérifier que le dossier `assets/` (textures, polices, sons) et les fichiers de sauvegarde se trouvent bien dans le répertoire de travail de l'exécutable.

## 🕹️ Commandes

* **Flèches Gauche / Droite :** Déplacer le bûcheron et couper l'arbre
* **Flèches Haut / Bas + Entrée :** Naviguer dans les menus
* **[Touche] :** [Ex. : Activer le bouclier / Mettre en pause]
